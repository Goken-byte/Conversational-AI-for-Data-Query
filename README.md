# Conversational-AI-for-Data-Query
Assume you have an excel file that has more 1000s of records for sales, using a Conversational-AI-for-Data-Query; you can feel like chatting with your salesperson asking him/her questions about the sales/business. the system will give you anwsers just like nothing.

# How to use it?
1- Clone/download the copy of this app from my github and host it on your server/localhost. run it from your browser,
2- Go to [https://openrouter.ai/keys] sign-in/sign-up if you have an account then click on Create API Key,
3- Copy the created API Key and come to the system and past it then click save,
4- Upload your EXCEL FILE and start enjoy chatting with system by asking questions base on the data you have in your excel file.
